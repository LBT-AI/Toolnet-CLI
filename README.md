# ToolNet CLI

ToolNet CLI is an AI coding agent for the terminal.

It runs as a standalone client and communicates with the ToolNet API Gateway through HTTP APIs.

## Features

- Interactive terminal UI
- Coding agent tools
- Build / Plan modes
- Workspace sandbox
- Permission approval
- Session persistence
- Context compaction
- File and image attachments
- Structured patch application
- Git status and diff
- Web fetch
- Optional browser automation
- MCP tools
- Teamwork / sub-agents
- Non-interactive mode for scripts and CI

## Requirements

Recommended:

- Bun

Node.js support is also built and tested where compatible.

## Development

```bash
bun install
bun run typecheck
bun test
bun run build
```
